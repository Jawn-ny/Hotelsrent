# 寿司小屋的租房记账程序
本程序基于租房需求，可用于多场景的记账，选择不同的功能反馈不同的界面用于帮助你更好的记录每一笔支出
## 基础功能
1.添加一笔支出(日期、物品、金额、分类、付款人、备注。);
2.查看所有支出记录;
3.按月份统计总支出;
4.按分类统计支出;
5.按付款人统计支出;
### 当前进度

- 已完成命令行版租房生活记账工具
- 已建立 FastAPI 开发环境
- 已实现 `GET /api/health` 健康检查接口
- 已实现 `GET /api/expenses`，可以读取并返回 JSON 文件中的全部支出。
- 已处理支出 JSON 文件损坏时的 HTTP 错误响应。
- 已实现 `POST /api/expenses`，可验证并保存新支出到 JSON 文件。
- 创建成功返回 `201 Created`。
- 支出金额必须大于 0。
- 物品名称、分类和付款人不能为空，并会自动清除首尾空格。
